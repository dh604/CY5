# Contents of this folder

- **`executed_batches/`**: contains multiple sets of julia files that were executed on the ETH servers to generate data.
- **`omega_data/`**: contains the conjectured membrane indices of those examples where the conjectured values are not generated by `GW_CY5.jl` in real time.
- **`results/`**: contains julia files that reproduce our results in the maximum range obtained when all results from `executed_batches/` are combined.
