# Overview

In this section, we explain how our PT calculations cited as *Evidence* in [main_paper](@cite) can be reproduced.

| Section/Space  | Evidence | Code |
| ----------- | ----------- | --- |
| [Closed vertex](closed_vertex.md) | Evidence 2.12 | closed_vertex.sage & closed_vertex.ipynb |
| [Local $\mathbb{P}^2$](local_P2.md) | Evidence 5.4 & 6.7 | local_P2.sage |
| [Local $\mathbb{P}^3$](local_P3.md) | Evidence 5.9  | local_P3.sage |
| [Local $\mathbb{P}^1 \times \mathbb{P}^1$](local_P1xP1.md) | Evidence 6.7 | local_P1xP1.sage |

!!! note
    Note that we executed most of the code listed in this section on a compute cluster provided by the Mathematics Department of ETH Zürich with the following metrics.
    - **Operating System:** Fedora
    - **CPU:** 1x AMD EPYC 7763 (64 Cores) 2.45GHz
    - **RAM:** 512 GB

    Therefore, it may be hard to reproduce some of our examples on an ordinary PC.
