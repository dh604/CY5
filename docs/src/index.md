# CY5.jl

_A Julia package to compute_ $\Omega_\beta$ _invariants of toric CY5s_

This Julia package accompanies the paper [main_paper](@cite) on equivariant Gromov-Witten invariants of equivariantly Calabi-Yau 5-folds.
Its purpose is to verify the conjectures of that paper in a number of cases, which are listed on this documentation page.

We build on the `flags` branch of the package [GKMtools.jl](https://mgemath.github.io/GKMtools.jl/) [HM25_paper, HM25_GKMtools](@cite) to compute equivariant Gromov-Witten invariants of the relevant spaces.
