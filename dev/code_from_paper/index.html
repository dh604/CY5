Example 1.1

In [HS26, Example 1.1], the GKM graph $G$ of $Z = \text{Tot}_{\mathbb{P}^1}(\mathcal{O}(-2))\times \mathbb{C}^3$ with a certain torus action is introduced. The following function can be used to obtain its GKM graph.

GW_CY5.gkm_graph_of_example_1_1 — Function
gkm_graph_of_example_1_1()

Return the GKM graph of $\text{Tot}_{\mathbb{P}^1}(\mathcal{O}(-2))\times\mathbb{C}^3$ as defined in [HS26, Example 1.1].

Example

julia> G = gkm_graph_of_example_1_1()

2 -> 1 => (1, -1, 0, 0, 0, 0)
Standalone flags:
1.2 => (2, 0, 1, 0, 0, 0)
1.3 => (0, 0, 0, 1, 0, 0)
1.4 => (0, 0, 0, 0, 1, 0)
1.5 => (0, 0, 0, 0, 0, 1)
2.2 => (0, 2, 1, 0, 0, 0)
2.3 => (0, 0, 0, 1, 0, 0)
2.4 => (0, 0, 0, 0, 1, 0)
2.5 => (0, 0, 0, 0, 0, 1)

Example 1.2

In [HS26, Example 1.2], we compute the Gromov-Witten of $Z$ in degrees $1,2,3$ and genus $0$ and $1$ using the following code.

julia> using Oscar, GKMtools, GW_CY5

julia> G = gkm_graph_of_example_1_1();

julia> beta = curve_class(G, Edge(1, 2));

julia> gMax = 1;

julia> GW = get_GW_beta(G, [beta, 2*beta, 3*beta], gMax; show_bar=false);
Calculating b=(1), g=0
Calculating b=(1), g=1
Calculating b=(2), g=0
Calculating b=(2), g=1
Calculating b=(3), g=0
Calculating b=(3), g=1

julia> GW[beta]

Example 1.4
