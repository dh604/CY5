Spaces

On this page, we list the implemented spaces and constructor functions that are compatible with the Pipeline. This means that they can be used in conjunction with get_Omega_prediction and hence with get_Omega_beta and its optional argument check_predictions=true.

Note

Only those functions that return a 5-dimensional result are compatible with the Pipeline. Functions returning a lower-dimensional result are listed because they are ingredients for 5-dimensional constructions.

GW_CY5.gkm_3d_strip — Function
gkm_3d_strip(ups_and_downs::Vector{Int64}; equiCY::Bool=false) -> GKMtools.AbstractGKM_graph

Create the GKM graph of the 3d strip geometry described by ups_and_downs (see [HS26, Section 2.1]).

Arguments

  • ups_and_downs: a vector of non-zero integers with the following meaning in terms of [HS26, (18)]: there will be ups_and_downs[1] flags up (if positive) or down (if negative), followed by ups_and_downs[2] flags up or down, and so on.
  • equiCY: If this optional argument with default value false is set to true, the returned space will be linearized to be equivariantly Calabi-Yau.

Weight convention:

In terms of [HS26, (18)]: flags pointing up have weight $\epsilon_2$, flags pointing down have weight $\epsilon_3$, and the flag at vertex 1 pointing left has weight $\epsilon_1$.

Example

Let us see the same example once with equiCY=false (default) and once with equiCY=true.

julia> G = gkm_3d_strip([1, -1, 1]) # equiCY=false
GKM graph with 3 nodes, valency 3 and axial function:
2 -> 1 => (1, 0, -1)
3 -> 2 => (1, -1, -1)
Standalone flags:
1.2 => (0, 1, 0)
1.3 => (1, 0, 0)
2.3 => (0, 0, 1)
3.2 => (-1, 1, 2)
3.3 => (0, 1, 0)

julia> G = gkm_3d_strip([1, -1, 1]; equiCY=true)
GKM graph with 3 nodes, valency 3 and axial function:
2 -> 1 => (-1, 1)
3 -> 2 => (-1, 0)
Standalone flags:
1.2 => (0, 1)
1.3 => (-1, 0)
2.3 => (0, -1)
3.2 => (1, -1)
3.3 => (0, 1)
