Evidence 5.5

On this page, we provide Julia code to verify the vanishing of certain Gromov-Witten invariants conjectured in [HS26, Conjecture 5.1]. The corresponding GKM graphs are obtained using CY5_from_CY4. After each line calling get_Omega_beta, we added the crucial line of the output as a comment.

$\mathcal{O}(-1)\oplus \mathcal{O}(-2)$

This example concerns the total space of $\mathcal{O}(-1)\oplus \mathcal{O}(-2)\oplus\mathcal{O}$ on $\mathbb{P}^2$. The curve calss b in the code corresponds to $H$ in the paper.

# Julia code to test GW vanishing for O(-1)+O(-2)+O on P^2

using Oscar, GKMtools, GW_CY5

CY4 = total_space(vector_bundle_O(2, [-1, -2]))
G = CY5_from_CY4(CY4; equiCY=true)

b = curve_class(G, Edge(1, 2))
max_genus = 3

get_Omega_beta(G, [b, 2*b, 3*b, 4*b], max_genus; check_predictions = true)
# All predictions hold

$\mathcal{O}(-1, -1)\oplus \mathcal{O}(-1, -1)$

This example concerns the total space of $\mathcal{O}(-1, -1)\oplus \mathcal{O}(-1, -1)\oplus\mathcal{O}$ on $\mathbb{P}^1\times\mathbb{P}^1$. The curve classes b,c in the code correspond to $(1, 0)$ and $(0, 1)$ in the paper.

# Julia code to test GW vanishing for (O(-1,-1)+O(-1,-1)+O on P1xP1

using Oscar, GKMtools, GW_CY5

P1_P1 = hirzebruch_surface(NormalToricVariety, 0)
P = picard_group(P1_P1)
L = toric_line_bundle(P1_P1, -P[1] - P[2]) # O(-1,-1)
CY4 = total_space(gkm_vector_bundle_of_toric([L, L]))
G = CY5_from_CY4(CY4; equiCY=true)

b = curve_class(G, Edge(1, 2))
c = curve_class(G, Edge(1, 4))

# perform tests

get_Omega_beta(G, [b, 2*b, 3*b, 4*b], 3; check_predictions = true)
# All predictions hold.

get_Omega_beta(G, [2*b+2*c], 3; check_predictions = true)
# All predictions hold.

get_Omega_beta(G, [2*b+c], 3; check_predictions = true)
# All predictions hold.

get_Omega_beta(G, [3*b+c], 3; check_predictions = true)
# All predictions hold.

$\mathcal{O}(-2, 0)\oplus \mathcal{O}(0, -2)$

This example concerns the total space of $\mathcal{O}(-2, 0)\oplus \mathcal{O}(0, -2)\oplus\mathcal{O}$ on $\mathbb{P}^1\times\mathbb{P}^1$. The curve classes b,c in the code correspond to $(1, 0)$ and $(0, 1)$ in the paper.

# Julia code to test GW vanishing for O(-2,0)+O(0,-2)+O on P1xP1

using Oscar, GKMtools, GW_CY5

P1_P1 = hirzebruch_surface(NormalToricVariety, 0)
P = picard_group(P1_P1)
L1 = toric_line_bundle(P1_P1, -2*P[1]) # O(-2, 0)
L2 = toric_line_bundle(P1_P1, -2*P[2]) # O(0, -2)
CY4 = total_space(gkm_vector_bundle_of_toric([L1, L2]))
G = CY5_from_CY4(CY4; equiCY=true)

b = curve_class(G, Edge(1, 2))
c = curve_class(G, Edge(1, 4))

get_Omega_beta(G, [2*b+2*c], 3; check_predictions = true)
# All predictions hold

get_Omega_beta(G, [2*b+c], 3; check_predictions = true)
# All predictions hold

get_Omega_beta(G, [3*b+c], 3; check_predictions = true)
# All predictions hold

get_Omega_beta(G, [b, 2*b, 3*b, 4*b], 3; check_predictions = true)
# Didn't get "All predictions hold":
# The computed Omega_beta was non-zero for b, zero for 2b, 3b, 4b.

The final line of code does not contradict [HS26, Conjecture 5.1]. Instead, it confirms that the properness assumption of the conjecture is necessary.
