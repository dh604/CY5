GW_CY5.jl

A Julia package to compute the membrane indices $\Omega_\beta$ of toric CY5s.

We build on the Julia package GKMtools.jl [HM25a, HM25b] to compute equivariant Gromov-Witten invariants of the relevant spaces.

Installation

First, install OSCAR using the instructions here. After that, open Julia and install GW_CY5.jl by typing the following code. This will automatically install the package GKMtools.jl on which GW_CY5.jl builds.

julia> using Pkg;
julia> Pkg.add(url="https://github.com/dh604/CY5")

You can now load the package by typing the following line.

julia> using Oscar, GKMtools, GW_CY5
