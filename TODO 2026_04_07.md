The .dat files in test/omega_data contain fractions of polynomials in q0, q1, q2, q3, q4 as follows:
* For each prefix p (like p="Omega_P3_13"), there are files called p_num.dat and p_den.dat.
* In both of these file, there is an equal number of lines, say N.
* For each d from 1 to N, let Qd be the polynomial in the d-th line of p_num.dat divided by the polynomial in the d-th line of p_den.dat.
* The resulting data type should be a fraction of the polynomial ring in q0, q1, q2, q3, q4, with rational coefficients.

## Your task:
1. Write a function that takes in the prefix p and some d_max and returns Q1, Q2, ..., Qn where n=min(d_max, N).
2. Write a function that takes the output of 1. as input, and substitutes qi = exp(ti) for each i. The expansion should be taken up to a certain degree in the ti's that is part of the input.
3. Write a function that takes as input the output of 2. and a vector of variables [T0,...,T4] and the variable u, and substitutes each ti by u*Ti.
4. Write a function that combines all of this, taking as input p, d_max, [T0,...,T4] and u.
