# CY5

Companion repository for the paper _Experiments with Membranes, Maps, and Sheaves_ by Daniel Holmes and Yannik Schuler.

**[Documentation Webpage](https://dh604.github.io/CY5/)**

## Contents:

- **GW_CY5.jl**: A Julia package to compute the membrane indices $\Omega_\beta$ of CY 5-folds from their Gromov-Witten invariants. We build on the Julia package [GKMtools.jl](https://mgemath.github.io/GKMtools.jl/) by Giosuè Muratore and Daniel Holmes to compute connected GW invariants of GKM spaces via equivariant localization.

- **PT_CY5.sage**: A SageMath package for computing K-theoretic PT invariants with Nekrasov-Okounkov insertions, building on Henry Liu's [boxcounting](https://github.com/liu-henry-hl/boxcounting).
